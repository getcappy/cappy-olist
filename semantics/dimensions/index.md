# Dimensions

13 dimensions available for slicing metrics.

* [Order date](date.md) - Date the order was placed (purchase timestamp).
* [Order status](order-status.md) - Order lifecycle status.
* [Customer state](customer-state.md) - Two-letter Brazilian state of the customer.
* [Delivery timeliness](delivery-timeliness.md) - Whether a delivered order arrived late.
* [Product category](category.md) - Product category in English.
* [Seller state](seller-state.md) - Two-letter Brazilian state of the seller.
* [Payment type](payment-type.md) - Payment method used for a transaction.
* [Instalment band](installment-band.md) - Number of payment instalments grouped into bands.
* [Review score](review-score.md) - Customer review score from 1 to 5.
* [Customer type](customer-type.md) - Repeat versus one-time customer.
* [Weight band](weight-band.md) - Product weight grouped into bands.
* [Customer first order date](customer-first-order-date.md) - Month of the customer's first order.
* [Review date](review-date.md) - Date the review was created.
